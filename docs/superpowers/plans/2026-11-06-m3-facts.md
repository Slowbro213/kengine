# M3: Fact and Consistency Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Check `fact` claims against the task's documents (retrieval + an entailment model), catch claims that contradict what's already established (consistency), and measure the effect on HotpotQA with vs. without.

**Architecture:** A new `kengine.retrieval` package holds the CPU-side models (ONNX entailment cross-encoder and sentence embedder, with fakes for tests), passage splitting, an in-memory SQLite FTS5 + vector corpus combined by reciprocal-rank fusion, and an optional SearXNG client. Three new evidence checkers use it: `facts` (spec §5.5 #5), `consistency` (§5.5 #4) and `inference-nli` (an addition, below). Checkers are built per task by `task_checkers(...)`, because the fact checker's corpus is the task's documents. The gate gets one more rule for document questions: the answer's words must appear in the claims it rests on.

**Tech Stack:** Python 3.12, onnxruntime, tokenizers, huggingface_hub, numpy, sqlite3 FTS5 (stdlib), httpx (already a dependency), pytest, pyright strict, ruff.

## Global Constraints

## Why these choices (from the spikes)

Three spikes ran the models on the claims from `eval/results/2026-11-03-hotpotqa-kengine-smoke-quick/sessions` (scripts in the session scratchpad, not the repo):

- `cross-encoder/nli-deberta-v3-base` scores unrelated text as *contradiction*, so it was dropped for the Xenova MNLI/FEVER/ANLI export. Even that one flags passages about **another entity** as contradicting at ≥ 0.95 ("X was born in 1950" vs. a passage about Y born in 1960). Two guards follow:
  - **fact check:** a contradiction counts only when no passage entails the fact, and the contradicting passage's document title (without a parenthetical like "(film)") is named in the fact
  - **consistency:** a pair is compared only if both claims share a proper name and the embedding cosine is ≥ 0.75, and it's a contradiction only if both directions score ≥ 0.9. On the spike pairs, different-entity pairs had cosine 0.49–0.68 (contradiction 0.98–1.00), real contradictions 0.78–0.90 (1.00/1.00), and a state change ("was mayor" / "is mayor") 0.85 with contradiction 0.14/0.27.
- Speed on the CPU: one fact check over 8 candidates takes about 0.25 s; embedding a HotpotQA item's 44–140 passages takes 0.3–1.6 s.
- Passages are sentences plus 2-sentence windows, each prefixed with `Title: `, so a claim that needs two sentences of one paragraph still has a single premise.
- Retrieval: FTS5 BM25 (top 20) and embedding cosine (top 20), fused by RRF with k = 60, top 8 kept.

**Decisions for the owner** (in the summary message, not blocking the build):

1. **`inference-nli` is an addition.** The spec gives informal inferences to the M5 critic. HotpotQA answers are bridge inferences ("the director of X was born in Y"), so without a check every answer stays blocked until M5. The entailment model scores the joined premise texts against the inference. It reaches at most `supported`, never `verified`, and only runs on tasks with documents.
2. The model choice and the ~870 MB download (`kengine fetch-models`).
3. SearXNG is built and tested against a mock, off by default; nothing is installed.
4. Spec retrieval items (a) project files indexed incrementally and (c) tool observations wait for M4, where the file and shell tools arrive. M3 covers (b) user documents (`kengine run --doc FILE`) and (d) web search.

```python
"""The CPU-side models (spec §5.5): an entailment cross-encoder and a sentence embedder,
both ONNX, pinned by revision and loaded from a local cache only. `kengine fetch-models`
downloads them."""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Protocol, cast

import numpy as np
import numpy.typing as npt
from huggingface_hub import hf_hub_download
from huggingface_hub.errors import LocalEntryNotFoundError
from tokenizers import Encoding, Tokenizer

Vectors = npt.NDArray[np.float32]

_FILES = ("onnx/model.onnx", "tokenizer.json")
_QUERY_PREFIX = "Represent this sentence for searching relevant passages: "
_BATCH = 32
_MAX_TOKENS = 512


@dataclass(frozen=True)
class NLIScores:
    entail: float
    neutral: float
    contradict: float


class EntailmentModel(Protocol):
    def score(self, pairs: Sequence[tuple[str, str]]) -> list[NLIScores]: ...


class Embedder(Protocol):
    def embed(self, texts: Sequence[str], query: bool = False) -> Vectors: ...


@dataclass(frozen=True)
class Models:
    entailment: EntailmentModel
    embedder: Embedder


@dataclass(frozen=True)
class ModelSpec:
    repo: str
    revision: str


ENTAILMENT = ModelSpec(
    "Xenova/DeBERTa-v3-base-mnli-fever-anli", "72a1ce83a0144efaf828b3c3844320a61197a53d"
)
EMBEDDING = ModelSpec("BAAI/bge-small-en-v1.5", "5c38ec7c405ec4b44b94cc5a9bb96e735b38267a")


class ModelsMissing(RuntimeError):
    pass


class _Session(Protocol):
    def get_inputs(self) -> list[Any]: ...
    def run(
        self, output_names: None, input_feed: dict[str, npt.NDArray[np.int64]]
    ) -> list[npt.NDArray[np.float32]]: ...


def _path(cache_dir: Path, spec: ModelSpec, filename: str, local_only: bool) -> Path:
    return Path(
        hf_hub_download(
            spec.repo,
            filename,
            revision=spec.revision,
            cache_dir=cache_dir,
            local_files_only=local_only,
        )
    )


def _open(cache_dir: Path, spec: ModelSpec) -> tuple[_Session, Tokenizer]:
    import onnxruntime  # pyright: ignore[reportMissingTypeStubs]

    model, tok = (_path(cache_dir, spec, f, local_only=True) for f in _FILES)
    session = cast(
        _Session,
        onnxruntime.InferenceSession(str(model), providers=["CPUExecutionProvider"]),
    )
    tokenizer = Tokenizer.from_file(str(tok))
    tokenizer.enable_truncation(_MAX_TOKENS)
    tokenizer.enable_padding()
    return session, tokenizer


def _feeds(session: _Session, enc: list[Encoding]) -> dict[str, npt.NDArray[np.int64]]:
    feeds = {
        "input_ids": np.array([e.ids for e in enc], np.int64),
        "attention_mask": np.array([e.attention_mask for e in enc], np.int64),
    }
    if "token_type_ids" in {i.name for i in session.get_inputs()}:
        feeds["token_type_ids"] = np.array([e.type_ids for e in enc], np.int64)
    return feeds


class OnnxEntailment:
    """Softmax over (entailment, neutral, contradiction) for each (premise, hypothesis)."""

    def __init__(self, session: _Session, tokenizer: Tokenizer) -> None:
        self._session, self._tok = session, tokenizer

    def score(self, pairs: Sequence[tuple[str, str]]) -> list[NLIScores]:
        out: list[NLIScores] = []
        for i in range(0, len(pairs), _BATCH):
            enc = self._tok.encode_batch(list(pairs[i : i + _BATCH]))
            logits = self._session.run(None, _feeds(self._session, enc))[0]
            p = np.exp(logits - logits.max(axis=1, keepdims=True))
            p = p / p.sum(axis=1, keepdims=True)
            out += [NLIScores(float(r[0]), float(r[1]), float(r[2])) for r in p]
        return out


class OnnxEmbedder:
    """CLS-pooled, normalized sentence vectors (bge)."""

    def __init__(self, session: _Session, tokenizer: Tokenizer) -> None:
        self._session, self._tok = session, tokenizer

    def embed(self, texts: Sequence[str], query: bool = False) -> Vectors:
        if query:
            texts = [_QUERY_PREFIX + t for t in texts]
        rows: list[Vectors] = []
        for i in range(0, len(texts), _BATCH):
            enc = self._tok.encode_batch(list(texts[i : i + _BATCH]))
            hidden = self._session.run(None, _feeds(self._session, enc))[0]
            cls = hidden[:, 0].astype(np.float32)
            rows.append(cls / np.linalg.norm(cls, axis=1, keepdims=True))
        return np.vstack(rows) if rows else np.zeros((0, 384), np.float32)


def models_present(
    cache_dir: Path, specs: Sequence[ModelSpec] = (ENTAILMENT, EMBEDDING)
) -> list[str]:
    """The repos in `specs` whose files aren't in `cache_dir`."""
    missing: list[str] = []
    for spec in specs:
        try:
            for f in _FILES:
                _path(cache_dir, spec, f, local_only=True)
        except LocalEntryNotFoundError:
            missing.append(spec.repo)
    return missing


def load_models(
    cache_dir: Path, entailment: ModelSpec = ENTAILMENT, embedding: ModelSpec = EMBEDDING
) -> Models:
    missing = models_present(cache_dir, (entailment, embedding))
    if missing:
        raise ModelsMissing(
            f"{', '.join(missing)} not in {cache_dir}; run `kengine fetch-models` (about 870 MB)"
        )
    return Models(OnnxEntailment(*_open(cache_dir, entailment)), OnnxEmbedder(*_open(cache_dir, embedding)))


def fetch_models(
    cache_dir: Path, specs: Sequence[ModelSpec] = (ENTAILMENT, EMBEDDING)
) -> list[Path]:
    return [_path(cache_dir, s, f, local_only=False) for s in specs for f in _FILES]
```

```python
"""Deterministic stand-ins for the CPU-side models, for tests."""

from __future__ import annotations

import re
import zlib
from collections.abc import Sequence

import numpy as np

from kengine.retrieval.models import NLIScores, Vectors

NEUTRAL = NLIScores(0.0, 1.0, 0.0)
_DIM = 64


class FakeEntailment:
    """A rule `(in_premise, hypothesis, scores)` applies when the hypothesis is equal and
    `in_premise` is part of the premise. Anything else is neutral."""

    def __init__(self, rules: Sequence[tuple[str, str, NLIScores]] = ()) -> None:
        self.rules = list(rules)
        self.calls: list[tuple[str, str]] = []

    def score(self, pairs: Sequence[tuple[str, str]]) -> list[NLIScores]:
        out: list[NLIScores] = []
        for premise, hypothesis in pairs:
            self.calls.append((premise, hypothesis))
            match = [s for p, h, s in self.rules if h == hypothesis and p in premise]
            out.append(match[0] if match else NEUTRAL)
        return out


class FakeEmbedder:
    """A hashed bag of lowercase words."""

    def embed(self, texts: Sequence[str], query: bool = False) -> Vectors:
        v = np.zeros((len(texts), _DIM), np.float32)
        for i, text in enumerate(texts):
            for w in re.findall(r"[a-z0-9]+", text.lower()):
                v[i, zlib.crc32(w.encode()) % _DIM] += 1.0
        norms = np.linalg.norm(v, axis=1, keepdims=True)
        return v / np.where(norms == 0, 1.0, norms)
```

```python
"""Documents as passages: each sentence, and each pair of neighbouring sentences, prefixed
with the document's title so a passage names what it's about."""

from __future__ import annotations

import re
from collections.abc import Sequence
from dataclasses import dataclass

_SENTENCE_RE = re.compile(r"(?<=[.!?])\s+")
_TITLE_RE = re.compile(r"^([^:\n]{1,120}): (.+)$", re.DOTALL)
_PAREN_RE = re.compile(r"\s*\([^)]*\)\s*$")


@dataclass(frozen=True)
class Passage:
    doc: int  # 1-based document number; 0 for web results
    title: str
    text: str  # starts with "<title>: "
    source: str = ""  # a web result's "url (fetched <time>)"


def bare_title(title: str) -> str:
    return _PAREN_RE.sub("", title)


def split_document(doc: str, number: int) -> list[Passage]:
    m = _TITLE_RE.match(doc.strip())
    title, body = (m.group(1), m.group(2)) if m else (f"Document {number}", doc.strip())
    sentences = [s.strip() for s in _SENTENCE_RE.split(body) if s.strip()]
    out: list[Passage] = []
    for i, s in enumerate(sentences):
        out.append(Passage(number, title, f"{title}: {s}"))
        if i + 1 < len(sentences):
            out.append(Passage(number, title, f"{title}: {s} {sentences[i + 1]}"))
    return out


def split_documents(docs: Sequence[str]) -> list[Passage]:
    return [p for i, d in enumerate(docs, 1) for p in split_document(d, i)]
```

```python
"""The corpus index (spec §5.5): SQLite FTS5 for keywords plus embeddings, combined by
reciprocal-rank fusion. In memory: a task's corpus lives as long as the task."""

from __future__ import annotations

import re
import sqlite3
from collections.abc import Sequence

import numpy as np

from kengine.retrieval.models import Embedder, Vectors
from kengine.retrieval.passages import Passage, split_documents

_WORD_RE = re.compile(r"\w+")
_RRF_K = 60
_POOL = 20


class Corpus:
    def __init__(self, embedder: Embedder) -> None:
        self._embedder = embedder
        self._passages: list[Passage] = []
        self._vectors: Vectors = np.zeros((0, 0), np.float32)
        self._db = sqlite3.connect(":memory:")
        self._db.execute("CREATE VIRTUAL TABLE p USING fts5(t)")

    @classmethod
    def from_documents(cls, docs: Sequence[str], embedder: Embedder) -> Corpus:
        corpus = cls(embedder)
        corpus.add(split_documents(docs))
        return corpus

    def __len__(self) -> int:
        return len(self._passages)

    def add(self, passages: Sequence[Passage]) -> None:
        if not passages:
            return
        start = len(self._passages)
        self._passages += passages
        self._db.executemany(
            "INSERT INTO p(rowid, t) VALUES (?, ?)",
            [(start + i, p.text) for i, p in enumerate(passages)],
        )
        new = self._embedder.embed([p.text for p in passages])
        self._vectors = new if start == 0 else np.vstack([self._vectors, new])

    def search(self, query: str, k: int = 8) -> list[Passage]:
        if not self._passages:
            return []
        score: dict[int, float] = {}
        for rank, row in enumerate(self._keyword(query)):
            score[row] = score.get(row, 0.0) + 1 / (_RRF_K + rank)
        q = self._embedder.embed([query], query=True)[0]
        for rank, row in enumerate(np.argsort(-(self._vectors @ q))[:_POOL]):
            score[int(row)] = score.get(int(row), 0.0) + 1 / (_RRF_K + rank)
        best = sorted(score, key=lambda r: (-score[r], r))[:k]
        return [self._passages[r] for r in best]

    def _keyword(self, query: str) -> list[int]:
        words = [w for w in _WORD_RE.findall(query.lower()) if len(w) > 2]
        if not words:
            return []
        match = " OR ".join(f'"{w}"' for w in dict.fromkeys(words))
        rows = self._db.execute(
            "SELECT rowid FROM p WHERE p MATCH ? ORDER BY bm25(p) LIMIT ?", (match, _POOL)
        )
        return [int(r[0]) for r in rows]
```

```python
"""The fact checker (spec §5.5 #5): retrieval plus the entailment model.

The top passages for a fact are scored as premises for it. A passage that entails it above
`verify_entail` makes it `verified`; above `support_entail`, `supported`. Contradiction
needs a guard: the entailment model also "contradicts" a fact with passages about another
person or thing, so a contradiction counts only when the passage's document is about
something the fact names. Both backing and contradiction is `conflicting`, and neither is
`insufficient`: both stay unchecked."""

from __future__ import annotations

from kengine.beliefs.status import Status
from kengine.checkers.base import BeliefView, CheckerKind, Outcome, Verdict
from kengine.claims.schema import Claim, ClaimType
from kengine.config import FactsConfig
from kengine.retrieval.index import Corpus
from kengine.retrieval.models import EntailmentModel, NLIScores
from kengine.retrieval.passages import Passage, bare_title
from kengine.retrieval.web import WebSearch, web_passages

_SHOWN = 200


def cite(p: Passage) -> str:
    where = f"web {p.source}, untrusted" if p.source else f"doc {p.doc}"
    return f"{where}: {p.text[:_SHOWN]}"


class FactChecker:
    id = "facts"
    kind = CheckerKind.EVIDENCE

    def __init__(
        self,
        corpus: Corpus,
        nli: EntailmentModel,
        cfg: FactsConfig,
        web: WebSearch | None = None,
    ) -> None:
        self._corpus, self._nli, self._cfg, self._web = corpus, nli, cfg, web

    def applies_to(self, claim: Claim) -> bool:
        return claim.type == ClaimType.FACT

    def check(self, claim: Claim, view: BeliefView) -> Verdict:
        verdict = self._judge(claim)
        if verdict.outcome == Outcome.UNKNOWN and not verdict.evidence and self._web:
            self._corpus.add(web_passages(self._web.search(claim.text)))
            verdict = self._judge(claim)
        return verdict

    def _judge(self, claim: Claim) -> Verdict:
        passages = self._corpus.search(claim.text, self._cfg.top_k)
        scores = self._nli.score([(p.text, claim.text) for p in passages])
        scored = list(zip(passages, scores, strict=True))
        backing = max(scored, key=lambda ps: ps[1].entail, default=None)
        against = [p for p, s in scored if s.contradict >= self._cfg.contradict and _names(claim, p)]
        backed = backing is not None and backing[1].entail >= self._cfg.support_entail
        if backed and against:
            assert backing is not None
            return self._verdict(
                Outcome.UNKNOWN,
                None,
                f"the documents both back and contradict it: {cite(backing[0])} / "
                f"{cite(against[0])}. Say which one you rely on and why",
                [cite(backing[0]), cite(against[0])],
            )
        if backed:
            assert backing is not None
            p, s = backing
            if s.entail >= self._cfg.verify_entail:
                return self._verdict(
                    Outcome.PASS, Status.VERIFIED, f"the documents state it: {cite(p)}", [cite(p)]
                )
            return self._verdict(
                Outcome.PASS,
                Status.SUPPORTED,
                f"the documents partly back it ({_pct(s)}): {cite(p)}",
                [cite(p)],
            )
        if against:
            return self._verdict(
                Outcome.FAIL,
                Status.CONTRADICTED,
                f"the documents say otherwise: {cite(against[0])}",
                [cite(against[0])],
            )
        return self._verdict(
            Outcome.UNKNOWN,
            None,
            "no document passage states this. Restate closely the sentence that says it and "
            "name its document, or drop the claim if no document says it",
            [],
        )

    def _verdict(
        self, outcome: Outcome, status: Status | None, explanation: str, evidence: list[str]
    ) -> Verdict:
        return Verdict(
            checker_id=self.id,
            checker_kind=self.kind,
            outcome=outcome,
            status=status,
            explanation=explanation,
            evidence=evidence,
        )


def _names(claim: Claim, p: Passage) -> bool:
    title = bare_title(p.title).lower()
    return bool(title) and title in claim.text.lower()


def _pct(s: NLIScores) -> str:
    return f"{round(s.entail * 100)}% entailment"
```

```python
already given or checked?

also "contradicts" claims about different people, so a pair is compared only when the two

from kengine.beliefs.records import BeliefRecord

_NOT_NAMES = frozenset(
    "The A An In On At It Its He She His Her They Their This That These Those There Then "
    "When While After Before So But And Or If As By For From Of To With Both Neither Either "
    "Yes No I We You".split()
)
_APPLIES = (ClaimType.FACT, ClaimType.DEFINITION)
_COMPARED = (ClaimType.FACT, ClaimType.DEFINITION, ClaimType.OBSERVATION)
_CHECKED = (Status.VERIFIED, Status.SUPPORTED)


def proper_names(text: str) -> set[str]:
    return {w for w in _NAME_RE.findall(text) if w not in _NOT_NAMES}


class ConsistencyChecker:
    id = "consistency"
    kind = CheckerKind.EVIDENCE

    def __init__(self, nli: EntailmentModel, embedder: Embedder, cfg: FactsConfig) -> None:
        self._nli, self._embedder, self._cfg = nli, embedder, cfg

    def applies_to(self, claim: Claim) -> bool:
        return claim.type in _APPLIES and claim.formal is None

    def check(self, claim: Claim, view: BeliefView) -> Verdict:
        names = proper_names(claim.text)
        others = [
            r
            for r in view.all()
            if r.claim.id != claim.id and _comparable(r) and names & proper_names(r.claim.text)
        ]
        if others:
            v = self._embedder.embed([claim.text, *(r.claim.text for r in others)])
            cos = v[1:] @ v[0]
            others = [r for r, c in zip(others, cos, strict=True) if c >= self._cfg.consistency_cosine]
        for r in others:
            a, b = self._nli.score([(r.claim.text, claim.text), (claim.text, r.claim.text)])
            if min(a.contradict, b.contradict) >= self._cfg.contradict:
                return self._verdict(
                    Outcome.FAIL,
                    Status.CONTRADICTED,
                    f"contradicts {r.claim.id}: {r.claim.text}",
                    [r.claim.id],
                )
        return self._verdict(
            Outcome.PASS, None, f"no conflict with {len(others)} close checked claim(s)", []
        )

    def _verdict(
        self, outcome: Outcome, status: Status | None, explanation: str, evidence: list[str]
    ) -> Verdict:
        return Verdict(
            checker_id=self.id,
            checker_kind=self.kind,
            outcome=outcome,
            status=status,
            explanation=explanation,
            evidence=evidence,
        )


def _comparable(r: BeliefRecord) -> bool:
    if r.claim.type == ClaimType.GIVEN:
        return True
    return r.claim.type in _COMPARED and r.status in _CHECKED
```

```python
"""An entailment-model check for inferences without formal content (added in M3; the spec
gives these to the M5 critic). The cited claims' texts, joined, are the premise. A strong
entailment makes the inference `supported`; it's a model's judgement, so never `verified`.
Only built for tasks with documents, where inferences bridge facts the fact checker has
checked."""

from __future__ import annotations

from kengine.beliefs.status import Status
from kengine.checkers.base import BeliefView, CheckerKind, Outcome, Verdict
from kengine.claims.schema import Claim, ClaimType
from kengine.config import FactsConfig
from kengine.retrieval.models import EntailmentModel


class InferenceEntailmentChecker:
    id = "inference-nli"
    kind = CheckerKind.EVIDENCE

    def __init__(self, nli: EntailmentModel, cfg: FactsConfig) -> None:
        self._nli, self._cfg = nli, cfg

    def applies_to(self, claim: Claim) -> bool:
        return claim.type == ClaimType.INFERENCE and bool(claim.premises) and claim.formal is None

    def check(self, claim: Claim, view: BeliefView) -> Verdict:
        cited = [p for p in claim.premises if view.exists(p)]
        premise = " ".join(view.get(p).claim.text for p in cited)
        (s,) = self._nli.score([(premise, claim.text)])
        names = ", ".join(cited)
        if s.entail >= self._cfg.inference_entail:
            return self._verdict(
                Outcome.PASS,
                Status.SUPPORTED,
                f"the entailment model finds it follows from {names} "
                f"({round(s.entail * 100)}%)",
                cited,
            )
        return self._verdict(
            Outcome.UNKNOWN,
            None,
            f"the entailment model doesn't find that it follows from {names}. State the "
            "missing link as a fact from the documents and cite it too",
            cited,
        )

    def _verdict(
        self, outcome: Outcome, status: Status | None, explanation: str, evidence: list[str]
    ) -> Verdict:
        return Verdict(
            checker_id=self.id,
            checker_kind=self.kind,
            outcome=outcome,
            status=status,
            explanation=explanation,
            evidence=evidence,
        )
```

```python
"""Web search for the fact checker (spec §5.5): pluggable, SearXNG by default, off unless
`facts.searxng_url` is set. Results are untrusted evidence: their text is only ever scored
as a premise, and feedback quoting them marks them untrusted. Only the result snippets are
used; pages aren't fetched."""

from __future__ import annotations

from collections.abc import Callable, Sequence
from dataclasses import dataclass
from datetime import UTC, datetime
from typing import Any, Protocol, cast

import httpx

from kengine.retrieval.passages import Passage


@dataclass(frozen=True)
class WebResult:
    url: str
    title: str
    content: str
    fetched_at: str  # ISO 8601, UTC


class WebSearch(Protocol):
    def search(self, query: str) -> list[WebResult]: ...


def web_passages(results: Sequence[WebResult]) -> list[Passage]:
    return [
        Passage(0, r.title, f"{r.title}: {r.content}", f"{r.url} (fetched {r.fetched_at})")
        for r in results
        if r.content.strip()
    ]


def _utc_now() -> datetime:
    return datetime.now(UTC)


class SearxngSearch:
    """A SearXNG instance's JSON API (`search.formats` must include `json` in its
    settings.yml)."""

    def __init__(
        self,
        base_url: str,
        client: httpx.Client | None = None,
        max_results: int = 5,
        now: Callable[[], datetime] = _utc_now,
    ) -> None:
        self._url = base_url.rstrip("/") + "/search"
        self._client = client or httpx.Client(timeout=15.0)
        self._max = max_results
        self._now = now

    def search(self, query: str) -> list[WebResult]:
        try:
            r = self._client.get(self._url, params={"q": query, "format": "json"})
        except httpx.HTTPError:
            return []
        if r.status_code != 200:
            return []
        when = self._now().strftime("%Y-%m-%dT%H:%M:%SZ")
        rows = cast(list[dict[str, Any]], r.json().get("results", []))
        out = [
            WebResult(str(x.get("url", "")), str(x.get("title", "")), str(x.get("content", "")), when)
            for x in rows
            if str(x.get("content", "")).strip()
        ]
        return out[: self._max]
```

```python
    caught before anything evaluates it."""
    return [StructureChecker(), ArithmeticChecker(), RestatementChecker(), LogicChecker()]


def task_checkers(
    documents: Sequence[str],
    has_givens: bool,
    models: Models | None,
    facts: FactsConfig,
    web: WebSearch | None = None,
) -> list[Checker]:
    """The checkers for one task. The fact checker's corpus is the task's documents (and the
    web, when configured), so it's built per task. Restatement only checks against givens,
    so a task of documents without givens leaves numeric facts to the fact checker."""
    out: list[Checker] = [StructureChecker(), ArithmeticChecker()]
    if has_givens or not documents:
        out.append(RestatementChecker())
    out.append(LogicChecker())
    if models is None:
        return out
    out.append(ConsistencyChecker(models.entailment, models.embedder, facts))
    if documents or web is not None:
        corpus = Corpus.from_documents(documents, models.embedder)
        out.append(FactChecker(corpus, models.entailment, facts, web))
        out.append(InferenceEntailmentChecker(models.entailment, facts))
    return out
```

```python
"""Replay the M3 checkers over the claims of earlier hotpotqa kengine sessions (no LLM) and
count verdicts, to check the thresholds. Usage:
    uv run python eval/scripts/facts_calibration.py <results dir> <out.json>"""

from __future__ import annotations

import json
import sys
from collections import Counter
from pathlib import Path

from kengine.beliefs.records import BeliefRecord
from kengine.beliefs.status import Status
from kengine.checkers.facts import FactChecker
from kengine.checkers.inference_nli import InferenceEntailmentChecker
from kengine.claims.schema import Claim
from kengine.config import load_config
from kengine.retrieval.index import Corpus
from kengine.retrieval.models import load_models


class Replay:
    def __init__(self, claims: dict[str, Claim]) -> None:
        self._r = {
            i: BeliefRecord(claim=c, status=Status.VERIFIED, status_reason="")
            for i, c in claims.items()
        }

    def get(self, id: str) -> BeliefRecord:
        return self._r[id]

    def exists(self, id: str) -> bool:
        return id in self._r

    def all(self) -> list[BeliefRecord]:
        return list(self._r.values())

    def premise_closure(self, ids: list[str]) -> list[str]:
        return list(ids)


def main(results: Path, out: Path) -> None:
    cfg = load_config([])
    models = load_models(cfg.models_dir)
    counts: Counter[str] = Counter()
    rows: list[dict[str, str]] = []
    for events_path in sorted(results.glob("sessions/*/events.jsonl")):
        events = [json.loads(line) for line in events_path.read_text().splitlines()]
        docs = events[0]["task"]["documents"]
        claims = {
            e["claim"]["id"]: Claim.model_validate(e["claim"])
            for e in events
            if e.get("kind") == "belief_added"
        }
        facts = FactChecker(Corpus.from_documents(docs, models.embedder), models.entailment, cfg.facts)
        infer = InferenceEntailmentChecker(models.entailment, cfg.facts)
        view = Replay(claims)
        for c in claims.values():
            for checker in (facts, infer):
                if checker.applies_to(c):
                    v = checker.check(c, view)
                    key = f"{checker.id}:{v.outcome}:{v.status}"
                    counts[key] += 1
                    rows.append({"session": events_path.parent.name, "claim": c.text, "verdict": key, "why": v.explanation})
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps({"counts": dict(counts), "rows": rows}, indent=1))
    print(json.dumps(dict(counts), indent=1))


if __name__ == "__main__":
    main(Path(sys.argv[1]), Path(sys.argv[2]))
```

```python
"""Count M3 verdicts in kengine sessions. Usage:
    uv run python eval/scripts/count_verdicts.py <results root>"""

from __future__ import annotations

import json
import sys
from collections import Counter
from pathlib import Path

CHECKERS = ("facts", "consistency", "inference-nli")


def main(root: Path) -> None:
    for run in sorted(p for p in root.iterdir() if (p / "sessions").is_dir()):
        counts: Counter[str] = Counter()
        fails: list[str] = []
        for events in run.glob("sessions/*/events.jsonl"):
            for line in events.read_text().splitlines():
                e = json.loads(line)
                v = e.get("verdict")
                if e.get("kind") != "verdict" or v is None or v["checker_id"] not in CHECKERS:
                    continue
                counts[f"{v['checker_id']} {v['outcome']} {v['status']}"] += 1
                if v["checker_id"] == "consistency" and v["outcome"] == "fail":
                    fails.append(f"{events.parent.name} {e['belief_id']}: {v['explanation']}")
        print(f"## {run.name}")
        for k, n in sorted(counts.items()):
            print(f"  {k}: {n}")
        for f in fails:
            print(f"  CONSISTENCY FAIL {f}")


if __name__ == "__main__":
    main(Path(sys.argv[1]))
```
